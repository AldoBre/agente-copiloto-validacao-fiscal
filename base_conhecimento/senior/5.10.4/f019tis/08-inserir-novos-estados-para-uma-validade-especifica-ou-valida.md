---
Ao informar uma validade já existente no sistema, são exibidos na tela somente os Estados/UF que ainda não estão cadastrados, respeitando os filtros informados nos campos.

## Exemplo

Hoje vendo para SC, PR e SP, mas a partir de agora irei vender para MT também, neste caso informo os campos Código Imposto Substituído, Aplicação de Substituição, Regime Tributário, Estado Destino como MT e a respectiva validade que desejo incluir neste estado. Na guia de Guia Substituição Imposto / Modalidade Base Cálculo por estado será exibido apenas o estado MT, o qual desejo cadastrar.
