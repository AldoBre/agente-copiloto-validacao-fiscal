Este critério de cálculo compara duas tabelas de preço para buscar o preço da substituição.

Caso a **Definição Base Cálculo Substituição** for:

* 2 - Considerar o menor preço, retornará o menor preço entre as duas tabelas.
* 3 - Considerar o maior preço, retornará o maior preço entre as duas tabelas.

Exemplo do cálculo para base:  
Tabela 1 = 10,00  
Tabela 2 = 15,00  
Quantidade = 5,00

Definição Base Cálculo Substituição = 2 - Considerar o menor preço  
10,00 \* 5,00 = 50,00

Definição Base Cálculo Substituição = 3 - Considerar o maior preço  
15,00 \* 5,00 = 75,00
