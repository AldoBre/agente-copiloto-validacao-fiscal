#### AGR.LCDPR.CODIGOIMOVELRURAL

Indica o código do imóvel rural padrão para as movimentações financeiras do LCDPR (Livro Caixa Digital do Produtor Rural).

|  |  |
| --- | --- |
| Valor (Numérico) | Descrição |
| 0 | Valor padrão |
| Qualquer valor maior que 0 | Código do imóvel rural previamente cadastrado no Cadastro de Imóveis Rurais (F603IMR) |
