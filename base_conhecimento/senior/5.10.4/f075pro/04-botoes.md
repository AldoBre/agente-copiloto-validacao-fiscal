# Botões

> **Fonte:** F075PRO - Cadastro de Produtos — versão 5.10.4  
> **URL:** https://documentacao.senior.com.br/gestaoempresarialerp/5.10.4/menu_cadastros/f075pro.htm  
> **Trilha:** Ajuda por telas > Cadastros > Produtos e Serviços > Produtos  
> **Telas citadas:** F055PPF, F075CRF, F075IMP, F075MCP, F113BUL, F700CMC  
> **Identificadores de regras:** —

---
Monta Cód. 

Acessa a tela de apoio Montagem do código Produto/Serviço (F075MCP).

Modelo  
Abre a tela F700CMC. Se o usuário estiver posicionado sobre um produto que possuir modelo cadastrado, este será carregado automaticamente na tela. Se o produto não possuir
modelo, a tela será aberta em modo de inserção, sugerindo a família, o código e a descrição do produto para o modelo.

Observação

O botão ficará habilitado apenas para produtos que pertençam à família do tipo "P - Produzido" ou "M - Montagem". A tela somente será chamada se o cursor estiver posicionado sobre o campo Produto (cabeçalho da tela) da guia D. Gerais.

Para que este botão abra a tela F700CMC é necessário que os usuários ou grupos a qual estes pertencem tenham permissão para a opção **Configuração de Grids**, através do menu Recursos > Configurações > Usuários > Configuração Telas.

Bula

Este botão abre a tela de Bula (F113BUL) para cadastro das informações do agrotóxico. Disponível apenas com a proprietária do Receituário Agronômico.

Inf. Técnicas

Acessado pela guia Derivações. Abre a tela de Características do produto no fabricante (F075CRF).

Prod. X Imp.

A partir deste botão, é aberta a tela Impostos por Produto (F075IMP). Os impostos só estarão disponíveis na tela se forem do tipo 76 - Agronegócio e estiverem cadastrados na tela Configuração de Impostos para a Filial (F055PPF).

Observação

Ao calcular os impostos da NF, o sistema irá buscar os impostos Agro da tela Impostos por Produto (F075IMP), de acordo com a data base correspondente.
