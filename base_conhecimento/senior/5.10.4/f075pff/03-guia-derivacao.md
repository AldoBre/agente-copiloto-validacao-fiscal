| **Guia Derivação** | |
| --- | --- |
| Campo | Descrição |
| Origem | Código da Origem. |
| Descr. (Origem) | Exibe a descrição da origem. |
| Família | Código da Família. |
| Descr. (Família) | Exibe a descrição da família. |
| Produto | Código do produto. |
| Derivação | Exibe a derivação do produto. |
| Fil. últ. entrada ST | Código da Filial da última entrada com ICMS ST para o produto/derivação |
| Nome (Fil. últ. entrada ST) | Nome da Filial da última entrada com ICMS ST para o produto/derivação |
| Preço Unit. Base ICMS Subst. | Valor base unitário do ICMS Substituto |
| % ICMS Subst. Última Entr. | Alíquota do ICMS retido por ST da última entrada |
| Valor Unit. ICMS Subst. | Valor unitário de ICMS substituído da última entrada |
| Base FCP ST ent. | Valor base unitário do FCP retido por ST da última entrada |
| % FCP ST últ. ent. | Alíquota do FCP retido por ST da última entrada |
| FCP ST últ. entrada | FCP retido por ST da última entrada |
| % CIDE Tec. | Percentual de imposto CIDE tecnologia |
| Sit. | Situação. Indicativo S= Sim ou N= Não. |
| Reg. Ent. Sai. | Permite configurar o campo Registrar entradas e saídas de um determinado produto e derivação. Se o campo for configurado como S - Sim, as novas notas fiscais de entrada serão registradas para fins de controle de impostos, e as notas fiscais de saída serão vinculadas a uma nota fiscal de entrada. |

Nota

Os valores de ICMS ST e FCP referentes à ultima entrada não serão atualizados ou zerados caso a nota de entrada seja reabilitada ou excluída.
