Ajuda por telas > Cadastros > Mercado e Suprimentos > Parâmetros Fiscais > Substituições Impostos/Modalidade Base Cálculo/Antecipação > Cadastro

Tela para cadastro de códigos de Impostos Substituído. Também é possível cadastrar o código para antecipação de ICMS.

## Campos

Tipo ICMS Substituído

Código do ICMS Substituído que será utilizado na tela Modalidade Base Cálculo (F019TIS).

Descrição

Descrição do ICMS substituído.

Abreviatura

Abreviatura do ICMS substituído.

Critério Cálculo Substituição

Critério para o cálculo das substituições tributárias ICMS, PIS, COFINS.

* " 1- Pela Margem de Lucro";
* "2 - Pelo Preço Unitário Base";
* "3 - Comparação da base calculada pela Margem e pelo Preço Unitário utilizando maior valor";
* "4 - Pela carga tributária média";
* "5 - Comparar duas tabelas de preço";
* "6 - Item enquadrado na PMPF/IVA ST comparando com PMC".

Para maiores informações acesse a tela Modalidade Base Cálculo (F019TIS).

Código da Antecipação

Código que identifica o tipo da Antecipação Tributária.

Excluir

Será possivel excluir um registro se o código não estiver vinculado a nenhuma parametrização no sistema.
