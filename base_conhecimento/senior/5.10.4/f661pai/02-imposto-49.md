* **Rateio das deduções entre os códigos de contribuições previdenciárias:** primeiro, será feito o rateio entre os códigos que já tenham alguma exclusão da base de cálculo. Se ainda houver valor a deduzir, o sistema irá fazer o rateio entre os outros códigos previdenciários que não tenham exclusão da base de cálculo. Esses valores rateados serão repassados para os códigos de ajustes vinculados ao código de contribuição previdenciária
